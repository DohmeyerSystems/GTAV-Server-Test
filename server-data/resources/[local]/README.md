# [local] – eigene Resources

Hier kommen **selbst geschriebene oder angepasste Scripts** hin.
Dieser Ordner wird von `scripts/vendor-resources.sh` **nie** überschrieben.

- Jede Resource = eigener Ordner mit `fxmanifest.lua`
- In `server.cfg` die Zeile `ensure [local]` einkommentieren
- Fremd-Scripts (aus GitHub) lieber in `resources.lock` eintragen statt hier hineinkopieren
